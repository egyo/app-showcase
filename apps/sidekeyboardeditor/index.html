Side Keyboard Editor

SIDE-KEYBOARD のキーとノブを割り当てる

SDINNOVATION の SIDE-KEYBOARD を USB で接続して設定する Mac アプリです。16個のキーと3つのノブを画面で選び、作業に合わせたショートカットをキーボード本体に保存できます。

開発中・非公開macOS 14以降 · Apple Silicon

主な機能

キーとノブを画面で選ぶ

4×4のキーに加え、各ノブの押下・左回転・右回転を編集できます。1つのキーに修飾キーを組み合わせるほか、メディアキーを割り当てたり、入力を無効にしたりできます。

本体で使うプロファイルを選ぶ

「本体プロファイル」を切り替えると、キーボードが使うプロファイルも変わります。対応機器は SDINNOVATION の SIDE-KEYBOARD（USB ID 0816:2475）です。

保存前の割り当てを残す

書き込み前の割り当てを Mac にバックアップし、書き込み後に本体から読み直して編集内容と照合します。必要に応じて、接続中の個体とプロファイルに対応する直近のバックアップを復元できます。

基本の使い方

  1. SIDE-KEYBOARD を USB で Mac に接続してアプリを開きます。
  2. キーまたはノブの操作を選び、「割り当ての種類」と必要なキー・修飾キーを設定します。
  3. 「本体に保存」を選び、読み戻しの結果を確認します。以前の割り当てに戻すときは「バックアップを復元」を使います。

開発状況

1.0.0 の開発版を紹介しています。アプリ本体とソースコードは非公開で、一般向けの配布は行っていません。機能や画面は変わる場合があります。

データの扱い

割り当ては USB 経由でキーボードに保存します。変更前の割り当ては Mac 内にバックアップします。
