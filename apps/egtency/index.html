iOS / Network

egtency

通信の応答時間を見えるように。移動中や画面を閉じている間の通信の変化を調べるための iPhone アプリです。

iPhone通信計測開発中・非公開

どんなアプリ？

egtency は、指定した宛先へ定期的に信号を送り、返事が届くまでの時間をミリ秒で表示します。新幹線などで移動するとき、回線の応答がどう変わるか、ほかのアプリを使っている間も計測が続くかを確かめるために作っています。

アプリ画面に加え、対応する iPhone ではロック画面の Live Activity や Dynamic Island に計測値を表示します。

主な機能

  • 1.1.1.1 または 8.8.8.8 を選んで通信の応答時間を計測。
  • 応答時間を色分けして表示。応答がない場合や表示が更新されていない場合も区別。
  • 計測ログを CSV として共有し、後から通信の変化を確認。
  • 開始から5時間で自動停止。iOS による中断時には、可能な場合に通知で案内。

基本的な使い方

  1. 計測先を 1.1.1.1 または 8.8.8.8 から選びます。
  2. 「開始」を押すと計測が始まります。必要に応じて Live Activity と通知を許可します。
  3. アプリ画面、ロック画面、対応機種の Dynamic Island で応答時間を確認します。
  4. 終えるときは「停止」を押します。記録を残す場合は「計測ログを共有」から CSV を保存します。

開発状況と注意点

現在は開発中の実証アプリで、一般公開・配布はしていません。 iOS 26 以降の iPhone を対象に開発し、iPhone 16 Pro で実機確認しています。

画面を閉じてから5時間の計測と自動終了に成功した例がありますが、別の試験では iOS が途中で計測を終了しました。常に計測を続けられる保証はありません。値が止まった場合は、アプリを開いて「開始」を押してください。

計測中は少量の通信と電池を使用します。モバイル回線ではデータ容量と電池残量にご注意ください。

掲載内容は 2026年9月時点の試作版に基づきます。画面写真は準備でき次第追加します。
