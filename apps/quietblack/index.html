macOS / Utility

QuietBlack

使っていない Mac の画面を、静かに黒く。メニューバーから操作できるシンプルな黒画面アプリです。

Macメニューバー開発中・非公開

どんなアプリ？

QuietBlack は、一定時間 Mac を操作しないと、接続しているすべてのディスプレイを黒一色で覆い、カーソルを隠します。マウスやキーボードの操作を検出すると、すぐに元の画面へ戻ります。

複数のコンピュータでマウスとキーボードを共有する ShareMouse 環境で、標準スクリーンセーバに代わるシンプルな表示を使いたい、という目的から生まれました。

主な機能

  • メニューバーの月アイコンから、無操作後に黒くするまでの待ち時間を選択。
  • 接続しているすべてのディスプレイを黒くし、表示中はカーソルを隠す。
  • マウス移動、クリック、キー入力などで解除。フェードなどのアニメーションは使わない。
  • 動画再生などで macOS が画面スリープの防止を要求している間は、自動表示を保留。
  • 手動での黒画面表示、最長10秒のテスト、ログイン時の起動に対応。

基本的な使い方

  1. macOS 標準スクリーンセーバの自動開始を無効にします。
  2. QuietBlack を起動し、メニューバーの月アイコンから待ち時間を選びます。
  3. 「2秒後にテスト（最長10秒）」で、黒画面と復帰を確認します。
  4. 必要に応じて「ログイン時に起動」を有効にします。2台の Mac で使う場合は、それぞれに設定します。

開発状況と注意点

現在は開発中で、一般公開・配布はしていません。 Apple Silicon 搭載 Mac の一部環境で動作を確認しています。

黒画面は画面ロックではありません。パスワードによる保護や、離席時の情報保護の代わりにはなりません。また、解除のためのクリックやキー入力は背後のアプリにも届く場合があります。まずマウスを動かして画面を確認してください。

掲載内容は 2026年9月時点の試作版に基づきます。画面写真は準備でき次第追加します。
