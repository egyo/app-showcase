egweb

よく使うサイトを専用ウインドウで開く

毎日開く Web サイトを、Mac の専用ウインドウから使えるアプリです。設定した URL を起動時に開き、フォームへの入力やサイト内の画面切り替えもできます。

開発中・非公開macOS 14以降 · Apple Silicon／Intel

主な機能

いつものサイトを開く

WebKit で設定した URL を開くと、サイト内のフォームや JavaScript による画面切り替えを使えます。Cookie の保存先は egweb 内のデータストアです。サイトによってはログイン状態を保持できます。

リンクと文字の大きさを設定する

通常の Web リンクを開くブラウザは macOS 版の設定で選べます。拡大率は50〜200%で調整でき、ホスト名ごとに保存されます。

端末認証でログイン情報を入力する

HTTPS サイトのログイン情報をキーチェーンに保存できます。対応するフォームでは端末認証後に入力されるので、内容を確認してサイト側のボタンで送信します。サイトによっては手入力や外部ブラウザでの認証が必要です。

基本の使い方

  1. egweb メニューの「設定」を開きます。⌘＋, でも開けます。
  2. 「サイト URL」に https:// または http:// から始まる URL を入力し、「サイトを保存」を選びます。
  3. 必要に応じて「リンクを開くブラウザ」を選びます。ページの更新は ⌘＋R、拡大・縮小は「表示」メニューから操作できます。

開発状況

1.3（ビルド4） の開発版を紹介しています。アプリ本体とソースコードは非公開で、一般向けの配布は行っていません。機能や画面は変わる場合があります。

iPhone・iPad 向けの開発版もあります。このページの操作手順は macOS 版を対象にしています。

データの扱い

表示するサイトに接続し、Cookie は egweb の WebKit データストアに保存します。ログイン情報を保存する場合は、端末のキーチェーンを使います。
