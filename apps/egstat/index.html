egstat

端末とネットワークの状態をひと目で確認する

iPhone の機種や OS、接続中の Wi-Fi やローカル IP アドレスを確認できるアプリです。よく見る項目はウィジェットに置けます。iPad と Mac にも対応しています。

開発中・非公開iOS／iPadOS 17以降 · macOS 14以降

主な機能

端末と接続の情報を見る

本体ではホスト名、機種、CPU、メモリ容量、OS、接続先の Wi-Fi 名、ローカル IP、取得できた DNS 設定を確認できます。稼働時間の表示は macOS 版に対応しています。

見たい項目に合わせてウィジェットを選ぶ

小・中・大の各サイズで「システム一覧」「ネットワーク中心」「情報グリッド」「ネットワーク簡易」から選べます。「ネットワーク簡易」ではローカル IPv4 を大きく表示します。

表示する情報を調整する

ホスト名や接続情報を表示したくないときは、本体の設定で隠せます。ウィジェットに載る Wi-Fi 名と時刻は本体で最後に取得したものです。ウィジェットの更新時刻は OS が決めます。

基本の使い方

  1. egstat を開き、端末や接続の情報を確認します。Wi-Fi 名を表示する場合は、本体で位置情報へのアクセスを許可します。
  2. 「ウィジェットをプレビュー」でサイズとデザインを見比べます。
  3. iPhone のホーム画面に egstat のウィジェットを追加します。追加後にウィジェットを編集し、「デザイン」から表示を切り替えます。

開発状況

0.1.3（ビルド4） の開発版を紹介しています。アプリ本体とソースコードは非公開で、一般向けの配布は行っていません。機能や画面は変わる場合があります。

データの扱い

表示に使う端末情報と接続情報は端末内で処理します。Wi-Fi 名の取得に位置情報の許可を使いますが、アプリは座標を取得しません。
