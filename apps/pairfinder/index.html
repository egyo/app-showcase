Finder を、そのまま使うために

資料を整理する場所と取り出す場所、作業中のフォルダと保管先。2つの場所を上下に開いたまま、いつもの Finder でファイルを扱いたい場面に向けて作っています。

独自のファイル一覧へ置き換えるのではなく、Finder のウィンドウ2枚を外側から連動させます。新しく作成した一組だけを管理し、すでに開いている別の Finder は管理対象にしません。

2枚を揃える手間を、少なく

移動も、大きさの変更も一緒に

どちらかのタイトルバーをドラッグすると、相手も追従します。一組の外周の端・角をドラッグすれば、幅と高さを揃えたまま全体をリサイズ。外周にポインタを合わせると、操作する方向のマークが出ます。

方向マークはウィンドウの外周に表示します。Finder が前面の間、システムカーソル自体は変わらない場合があります。中央の境界で上下の比率を変える機能はありません。

それぞれの開始位置と、好みの隙間

上下別々にフォルダまたは「コンピュータ」を指定できます。新しく開くときは、その場所をリスト表示で開きます。閲覧中は表示方法も移動先も自由に変更できます。

間の隙間は0〜80pt・2pt刻みで調整します。現在の初期値は32ptで、0ptを含む保存済みの値は維持します。表示中の一組にも反映し、隙間を除く高さを上下で半分ずつにします。前回のディスプレイ・画面内の位置・全体の大きさも保存して復元します。

隠す、戻す、閉じるを一組で

片方の黄色いボタンで2枚を最小化し、復元も連動します。PairFinder の Dock アイコンを再クリックすれば、見ていた場所を維持して前面へ。片方を閉じると相手も閉じます。メニューバーの専用メニューからも操作できます。

通常のSpacesの往復やディスプレイスリープでも、同じ2枚の連動を保持します。別のSpaceやスリープ中は操作を待機し、復帰後に元の2枚を確認して再開します。ウィンドウ情報が戻るまで、設定画面に待機状態を表示します。

アプリの配置を復元する

起動中に各アプリで最後にフォーカスした通常ウィンドウのディスプレイ・位置・サイズを保存し、次回そのアプリを起動したときに最初の通常ウィンドウ1枚を復元します。初期設定はオンで、設定から切り替えられます。保存先の画面が未接続ならメインディスプレイに収めます。各アプリの最小サイズなどの制限を受け、元の位置に一瞬表示される場合があります。

iCloud Driveの再同期を要求する

メニューから再同期を要求できます。Dockアイコンから一組を表示・再表示・復元したときも、表示と内容の更新要求の後に1回実行します。片側の選択や監視、設定画面・メニューからの一組の表示だけでは自動実行しません。結果は終了要求を送れたかを示すもので、クラウドの同期完了を意味しません。

実際の設定画面

基本の使い方

以下はアクセス権のある試用者向けの手順です。一般向けのダウンロードは用意していません。設定画面が自動で開くのは初回だけです。2回目以降は保存した開始位置で一組を開き、設定はメニューの「設定…」から確認・変更します。

  1. 上下の開始位置を選ぶ。初回起動時の設定画面で「上」「下」の「選択…」から、それぞれフォルダまたは「コンピュータ」を指定します。
  2. Finder を操作する許可を与える。「アクセシビリティ設定を開く」から PairFinder を許可します。最初の Finder 操作時に表示されるオートメーション確認でも許可してください。
  3. 「一組を開く」で使い始める。新しい Finder 2枚が上下に開きます。移動はタイトルバー、リサイズは一組の外周から行います。
  4. 必要なら隙間を調整する。メニューバーの PairFinder メニュー →「設定…」を開き、スライダーを動かします。最小化中の変更は復元時に反映します。
  5. 作業に合わせて閉じる・解除する。2枚を閉じるなら赤いボタンや「一組を閉じる」を使います。Finder を残すなら「連動を解除」を選び、PairFinder は起動したままにしてください。PairFinder を明示的に終了すると、連動外・最小化中・別のSpaceにあるものも含め、閉じられるすべての Finder ウィンドウを閉じます。Finder 自体は終了しません。

開始位置の変更と、再表示は別の動作です。開始位置を変えた後は、現在の一組を閉じてから開き直すと反映します。開いている一組を Dock アイコンで呼び出すだけなら、現在の閲覧先を維持します。

必要な許可と情報の扱い

アクセシビリティは Finder の連動と各アプリのウィンドウ復元に、オートメーション → Finderはウィンドウの作成・識別・閉じる操作に使います。明示的な終了時には連動外を含む Finder ウィンドウも閉じます。システム設定の「プライバシーとセキュリティ」で許可を変更できます。フルディスクアクセスや入力監視は要求しません。

上下の開始位置、隙間、一組の配置、各アプリのディスプレイ・位置・サイズは Mac 内に保存します。ファイルの内容や利用情報を開発者のサーバーへ自動送信する機能はありません。共有やクラウド上の場所を開く場合やiCloud Driveの再同期を要求した場合、Finder や OS 側で通信が発生することがあります。

エラーや操作の診断情報は macOS のログに出力します。画面・ログを共有するときは、不要な名前やパスを確認してください。詳しくはプライバシーポリシーの PairFinder 節へ。

利用前に知っておきたいこと

  • 上下1組・常に等分。左右配置、複数組、中央境界での比率調整はありません。
  • 対象を確認できない場合は連動を解除。タブの追加・結合、フルスクリーン、Finder 再起動、権限失効などではウィンドウを残して停止します。通常のSpaces往復とディスプレイスリープでは待機して再開します。設定画面の案内を確認してください。
  • すべてのウィンドウ管理環境には未対応。ディスプレイをまたぐ移動と位置復元には対応しています。ウィンドウを別々のSpaceへ移す操作、緑のボタン、タイル、Stage Managerの全面対応は保証していません。
  • 2枚は独立した Finder です。応答速度や最小化アニメーションの影響を受けます。長時間・高負荷や Finder の表示設定の違いは継続検証中です。
