iOS / Camera

egcamera

撮る前に色を選ぶ。仕上がりを楽しみながら、編集できる元画像も残す写真専用の iPhone カメラです。

iPhone写真・LUT開発中・非公開

どんなアプリ？

egcamera は、写真に色味を付ける LUT を選び、その効果をプレビューしながら撮影するアプリです。試作版では、LUT を選択して有効にすると、LUT 適用済みの HEIF と、LUT 未適用の Apple ProRAW DNG を独立した2枚として写真ライブラリへ保存します。LUT を使わない場合は DNG のみを保存します。

好みの仕上がりをその場で得ながら、後で編集するための元画像も残すことを目指しています。HEIF はカメラが生成した処理済み画像に LUT を適用したもので、DNG をアプリ内で現像した画像ではありません。動画、Live Photos、ポートレート撮影には対応していません。

主な機能

  • 対応範囲内の3D .cube LUT をファイルから読み込み、複数保存。選択した LUT を撮影前のプレビューと完成 HEIF に適用。
  • 撮影画面の「35 / 48 / 120」で画角を切り替え。設定には「13 / 24 / 35 / 48 / 85 / 120」の選択肢があります。mm 表示と実際の画角の対応は検証中です。
  • 露出補正、フラッシュ、タイマー、タップによるピント・露出合わせ、長押しの AE/AF ロック、水平器を実装。各撮影条件での確認を続けています。
  • カメラコントロールからの起動とシャッター操作に対応。ロック中は LUT を使わず DNG のみを撮影し、「LUT撮影へ」から認証を経て通常アプリへ移る設計です。ロック中の撮影・保存は個別の実機確認を継続しています。

基本的な使い方

  1. アプリを開き、カメラの使用を許可します。写真への追加権限は最初の保存時に求められます。
  2. 色味を変えたい場合は設定から .cube ファイルを読み込み、使う LUT を選びます。読み込み前に LUT の入力プロファイルを選びます。この設定は次に読み込む LUT に適用されます。
  3. 撮影画面で構図と画角を決め、必要に応じて露出などを調整してシャッターを押します。
  4. 撮影後、写真ライブラリで保存された画像を確認します。画面の写真ボタンはシステムの写真ピッカーを開きます。保存画像の確認は写真.appで行ってください。保存に失敗した場合は、設定の「保留画像を再保存」から再試行します。

設定と写真ピッカーは縦持ちで操作してください。設定を開くと、LUT 見本のために写真の読み取り・書き込み権限も求められます。許可しなくても、カメラと追加保存の権限があれば撮影できます。

開発状況と対応範囲

現在は開発中の試作版で、一般公開・配布はしていません。 現行の試作版は iOS 26 以降の iPhone 16 Pro / 16 Pro Max を対象にしています。今後の機種や機能の対応は検証後に決めます。

iPhone 16 Pro では、通常アプリの基本撮影、LUT の読み込み、DNG の保存、カメラコントロールからの起動を実機で確認しています。16 Pro Max や全撮影条件での動作確認が完了したことを意味しません。一方、フレーム外表示やナイトモードは未実装です。LUT 適用後の HEIF の色、画像の向き、各画角での解像度、ロック中の撮影・保存などは継続検証しています。

LUT は格子サイズ2〜65、RGB 値0〜1、入力範囲0〜1の3D .cube に対応します。1D LUT や範囲外のデータは読み込めません。F-Log2C 入力は近似処理で、F-Gamut C への色域変換は未実装です。プレビューと HEIF の色や、富士フイルム機との色一致を保証するものではありません。
