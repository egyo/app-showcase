macOS / Prompt Composer

ExpressGenesis

描きたいイメージを、
伝わる言葉へ。

被写体も、画風も、仕上がりのサイズも。画像生成の希望をフォームにまとめ、ChatGPT に貼り付ける日本語プロンプトを作る Mac アプリです。

macOS 26 以降Apple Silicon 専用開発中・非公開
使い方を見る ↓
アプリ本体・ソースコードは開発中・非公開で、一般向けの公開・配布は行っていません。このページでは開発中の機能と操作を紹介しています。
  1. 01 / COMPOSE希望を整理する自由文と候補語で入力
  2. 02 / COPYプロンプトを作る文章を生成・自動コピー
  3. 03 / CREATEChatGPT へ貼り付ける参考資料は別途添付

思い描くことと、仕上げたい形を一緒に

描いてほしい主役、参考画像から取り入れたい雰囲気、壁紙に使う完成サイズ。条件が増えるほど、依頼の文章を整えるのにも手間がかかります。ExpressGenesis は、その希望を項目ごとに整理して、一つの指示文にまとめるために作っています。

アプリ内で行うのは、入力内容の検証・文章の組み立て・コピーです。画像の生成・拡大・ZIP 作成は ChatGPT 側へ依頼します。画像・音楽・ZIP の読み込み・内容確認、自動添付、自動送信は行いません。

言葉を選ぶところから、コピーまで

13項目で、描きたいことを具体的に

用途、被写体・モチーフ、シーン、表情・動作、画風・質感、構図、光、色、ディテール・別案、守る条件、避けたいこと、任せる範囲、画像内の文字・配置を入力できます。すべてを埋める必要はありません。

説明付きの候補から、表現を探す

創作内容の13項目に777の説明付き候補を収録。人物・壁紙・サムネイル制作を想定して候補を補い、選びやすい順へ整理しています。視線を逸らす・上目遣い・見つめ合う、眩しすぎない、瞳孔をハートマークにする・艶やかな唇・絶対領域も選べます。「候補一覧」を開き、ボタンにマウスを合わせると説明を表示します。候補は入力欄の末尾へ追加し、文字を選択しているときはその部分を置き換えます。手入力での編集や、欄ごとの消去もできます。

参考資料の役割を、混ぜずに伝える

参考画像・音楽（MP3/AAC）・それぞれを含む ZIP のファイル名と、参考にする点・維持する点・変更してよい点を記入。「各資料から個別に制作」「組み合わせて一作品」「資料ごとの役割を分けて参照」を選べます。主役のモチーフと、構図や雰囲気の参考を分けて指定できます。

サイズと仕上げの希望も、同じ文章へ

iPhone・iPad・Mac・YouTube サムネイル用の希望完成サイズや独自サイズを追加し、複数の出力先を指定できます。PNG／JPEG／HEIC／BMP（透過対応）／PSD、縦横比の調整、拡大方針、原本を含めるかも選択。ZIP にまとめて納品する依頼を、文章の末尾に添えます。

PSD の編集用データや、サムネイルの容量も指定

PSD を選ぶと、背景・人物・小物・文字などを個別に編集できるレイヤーへ分ける指示を加えます。「YouTubeサムネイルを追加」は横3,840×縦2,160 px。容量上限は1ファイルごとの任意の整数 MB で、YouTube 用はパソコン向け50 MBが初期値です。モバイル向け2 MBや指定なしにも変更できます。

BMP・HEIC・PSD と YouTube 用を併用すると、選択形式の画像に加え、投稿用PNG/JPEGを依頼します。YouTube の容量上限は投稿用画像に適用します。PSD作成・圧縮・実容量の検査は、生成先へ依頼する処理です。数値の出典はYouTube公式ヘルプ（2026年10月22日確認）です。

よく使う条件をプリセットに

創作内容の入力があるカテゴリだけを、8文字以内の名前と好きな色で保存できます。左側のボタンから確認して適用すると、保存してあるカテゴリだけを置き換えます。名前・色の編集や削除も可能で、初回には「高画質化」を登録します。参考資料と出力設定は創作プリセットに含めません。

出力設定を、次の制作にも引き継ぐ

作品数・出力先・形式・拡大方法など「出力・仕上げ」の変更を自動保存し、新規入力画面と次回起動で復元します。保存前の初期値はPNG・背景拡張・細部の生成的な補完を許可・ランチョス補間・完成画像のみ。iPad・iPad mini用は4,096×4,096 pxの正方形で、縦横回転と中央60％の保護を依頼します。

生成結果を確認して、すぐに渡す

「プロンプト生成」または ⌘＋Return で文章を生成し、自動コピー。「生成結果」で内容を確認できます。入力を変えると再生成を案内し、入力不備があるときはクリップボードを書き換えません。

参考資料と仕上げを、画面で確認

掲載3枚は2026年10月25日に開発者が提供した0.1.15（17）の実画面です。周囲のデスクトップを含まない提供PNGをそのまま掲載しています。撮影時の入力例であり、標準プリセットや初期状態の全項目を示すものではありません。候補一覧の表示件数は撮影時点の値です。本文の777候補と保存処理の改善は0.1.16（18）の内容です。

プロンプトを渡して、画像制作へ

子猫の浮世絵風イラストを依頼している利用風景です。右の ExpressGenesis で創作条件・作品数・完成形式を文章にまとめ、左の ChatGPT 側で画像制作を進めています。

基本の使い方

アクセス権のある試用者向けの操作です。一般向けのダウンロードは用意していません。

  1. 「創作内容」を入力する。被写体・シーン・参考資料のいずれかで、何を作るかを指定します。自由文と候補語を組み合わせ、必要な欄だけ記入してください。
  2. 必要なら「参考資料」を追加する。実際に添付するファイル名と役割を入力し、資料の扱い方を選びます。画像入り ZIP の枚数と音楽入り ZIP の曲数は任意の手入力で、アプリが中身を数えるものではありません。
  3. 「出力・仕上げ」を選ぶ。作品数、希望完成サイズ、形式、縦横比と拡大の方針を指定します。Mac の壁紙なら「Mac用を追加」、動画サムネイルなら「YouTubeサムネイルを追加」で、それぞれ横3,840×縦2,160 px を追加できます。拡大の初期値は「細部の生成的な補完を許可」です。忠実さを優先する場合は「構図・色調を保つ拡大」へ変更します。
  4. 「プロンプト生成」で文章をコピーする。生成結果を読み、コピーの成功表示を確認します。コピーできない場合は、生成結果の文章を選択して手動でコピーできます。
  5. ChatGPT へ貼り付ける。参考資料を使う場合は、文章に記載した名前と一致する実ファイルを ChatGPT 側で添付して送信します。入力を修正したら、再生成・再コピーしてください。未生成の変更があるまま閉じる際は確認が出ます。保存したプリセットと出力設定は終了後も残ります。

たとえば、Mac の壁紙を依頼するなら

入力例 / 架空の制作条件

用途・主役
Mac の壁紙。月明かりの庭にいる白い猫。
画風・構図
水彩風。主役は右寄せ、左側に余白を残す。
出力・仕上げ
1作品、Mac 用 3,840×2,160 px、PNG。背景拡張と「構図・色調を保つ拡大」を明示選択。

この条件を入力して生成すると、創作内容と仕上げの希望、実寸法・形式の確認、ZIP 納品の依頼をまとめた文章になります。

入力例は使い方を示すもので、生成画像や納品結果の作例ではありません。

利用前に知っておきたいこと

  • 希望サイズと実際の納品サイズを区別します。プリセットは希望する完成ピクセル寸法です。端末の物理解像度や、壁紙の空間シーン機能の動作を保証するものではありません。
  • 必要な未指定事項は、制作前の確認を依頼します。空の任意見出しは省略し、作品数やサイズなどが未指定なら、生成文で受け手に確認を求めます。自由文の意味の矛盾や参考画像の中身を自動判定する機能はありません。
  • 画像の完成には、ChatGPT 側での操作が必要です。文章のコピー成功は、画像生成・拡大・ZIP 納品の完了を意味しません。生成後の画質・形式・実寸法・ZIP 内容は、受け取ったファイルで確認してください。

入力とクリップボードの扱い

明示保存した創作プリセットと「出力・仕上げ」の設定はMac内に保存し、新規画面と次回起動で利用します。未保存の創作内容・参考資料の指定・生成文はメモリ内だけに保持し、終了すると破棄します。作業履歴や参考ファイル自体は保存しません。アプリから外部サービスへ自動送信する機能はありません。保存設定はアプリ独自の暗号化を行いません。

生成した文章は macOS の一般クリップボードへ書き込みます。アプリを終了してもコピー済みの文章まで消去する機能はありません。配布済み0.1.16では、OSのユニバーサルクリップボードやクリップボード管理アプリによって他端末へ共有・保存される場合があります。

2026年10月25日の後続ソース修正では、自動コピーをこのMac内に限定する方針を追加しました。今回の修正は未ビルド・未配布で、配布済み0.1.16には含まれません。手動コピーや他アプリの履歴・独自同期は別の扱いです。

ChatGPT に貼り付けて送信した文章と添付資料は、送信先のサービスや利用者の設定に従って扱われます。詳しくはプライバシーポリシーの ExpressGenesis 節へ。
